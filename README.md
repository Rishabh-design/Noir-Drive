# NoirDrive

Luxury and exotic car rental website, built from the Figma design "Rental Luxury Car Website".

- **Stack:** Next.js 14 (App Router), TypeScript, CSS Modules, GSAP (ScrollTrigger, SplitText), Lenis smooth scroll
- **Run locally:** `npm install` then `npm run dev` → http://localhost:3100

Sizing follows the 1728px Figma frame: on desktop `1rem = 10 design px`, scaled with the viewport.
